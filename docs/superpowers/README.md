# Implementation archive

This directory preserves dated design proposals, implementation plans, spikes,
and codebase reviews. It records how features were discussed and built.
Documents here may describe superseded behavior, incomplete sequencing, or
temporary constraints.

A review under [`reviews/`](reviews/) is a snapshot of findings at one commit.
Its severities and file references age with the code: treat a finding as a
claim to re-verify, not as a current defect list. Findings that were acted on
are traceable through the spec that cites them.

Use [`docs/README.md`](../README.md) and [`docs/current/`](../current/) for the
maintained description of Geode. When an archived decision still explains an
important tradeoff, summarize that reason in the relevant current guide rather
than making the archive required reading.

Files in this directory are retained for historical traceability. Do not amend
them to describe later behavior; update the current guide instead.
